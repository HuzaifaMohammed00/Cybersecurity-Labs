# Cybersecurity Labs
A personal collection of hands-on cybersecurity practice — CTF write-ups, notes from learning platforms, and small experimental scripts, built while working toward becoming a cybersecurity analyst.

## What's in here

This repo is a working lab notebook, not a single polished project. It's organized into three main areas:

### 🚩 CTF Write-ups
Solutions and walkthroughs from Capture The Flag competitions and challenges (e.g. picoCTF, qualifier events). Each write-up covers the approach, tools used, and key takeaways — not just the final flag.

### 📘 TryHackMe & picoCTF Notes
Structured notes from rooms and challenges completed on TryHackMe and picoCTF — summarizing concepts learned (networking, web exploitation, session hijacking, etc.) rather than just raw answers.

### 🧪 Scripts & Experiments
Small, standalone scripts and mini-experiments used for practice — things like exploring SQL injection payloads, testing broken access control with Burp Suite, or trying out a new tool for the first time. These are exploratory, not full projects.

## Suggested structure

```
cybersecurity-labs/
├── ctf-writeups/
│   └── <event-name>/
├── tryhackme-picoctf-notes/
│   └── <room-or-challenge-name>/
├── scripts-experiments/
│   └── <short-script-name>/
└── README.md
```

Each subfolder gets its own short `README.md` or notes file explaining what it covers.
